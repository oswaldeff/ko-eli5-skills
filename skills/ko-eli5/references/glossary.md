# Glossary (EN → KO, fixed)

Single source of truth for terminology. `style-guide`'s Terminology check loads this table as the
authoritative list. Start small; add a row every time a report introduces a new term.

| English | Korean (use this) | Do not use | Note |
|---|---|---|---|
| measured / inferred / assumed | 확인 / 추정 / 가정 | 측정됨 / 유추됨 / 전제 | these are the label words; never vary |
| done / partial / failed / blocked | 완료 / 일부 완료 / 실패 / 막힘 | 성공 / 부분 완료 / 에러 | status words; first line of report |
| idempotency | 멱등성 | 아이덤포턴시 | first use: 멱등성(idempotency) |
| consumer group | 컨슈머 그룹 | 소비자 그룹 | keep loanword |
| ack / acknowledge | 처리 확인(ack) | 승인 | "승인" implies human approval |
