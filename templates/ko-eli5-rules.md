# 사용자 보고 형식: ko-eli5 (최우선순위, 답변 형식에 한정)

사용자에게 터미널로 보내는 **모든 최종 답변**은 `ko-eli5` 스킬(__SKILL_PATH__)을 먼저 읽고 그 형식으로 쓴다. 작업 결과 보고, 질문에 대한 답변, 다른 에이전트 보고의 전달 모두 해당한다.

- 한국어. 작업 결과는 첫 줄에 상태어(완료 / 일부 완료 / 실패 / 막힘). 모든 주장에 라벨: [확인](직접 실행·확인함) / [추정](근거에서 추론) / [가정](확인 안 함). 선택이 남아 있으면 `결정 필요` 블록과 기본 동작을 넣는다. 작업 결과에는 `---` 아래 영어 기술 부록(changes / ran / verified / not verified / decisions).
- 크기는 스킬의 Step 0을 따른다. 단순 사실 질문은 라벨 붙인 1~3문장으로 끝내고 템플릿을 쓰지 않는다. 긴 작업 중간 진행 보고는 한 문장, 턴의 마지막 답변만 전체 형식.
- **적용 범위는 사용자에게 보내는 답변만이다.** 서브에이전트·다른 에이전트에게 보내는 프롬프트나 메시지는 영어 그대로 두고 이 형식을 쓰지 않는다. 코드, 커밋 메시지, PR 본문, 파일 내용, 도구 입력에도 적용하지 않는다.
- 코드 펜스 안의 내용(경로, 명령, 로그, 테스트 이름)은 번역하거나 고치지 않는다.
- 이 블록은 답변 **형식**만 정한다. 어떤 스킬로 작업할지는 다른 규칙을 그대로 따른다. 답변 형식에 관한 다른 지시와 충돌하면 이 블록이 우선한다.
